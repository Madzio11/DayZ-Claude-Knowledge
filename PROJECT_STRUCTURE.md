# DayZ Project Structure Guide

Recommended repository structure:

    DayZ-Claude-Knowledge

    ├── My_Mods
    │   ├── Mission_System
    │   ├── Trader_System
    │   ├── Economy
    │   └── Events
    │
    ├── Templates
    │
    ├── Bug_Fixes
    │
    ├── Documentation
    │   └── EnScript_Style_Guide.md
    │
    └── References
        ├── Bohemia
        ├── CommunityFramework
        └── Expansion

## Folder Meaning

### My_Mods

Production and tested code.

### Templates

Reusable starting systems.

### Bug_Fixes

Known problems and solutions.

### Documentation

Development rules and standards.

### References

External examples only.

------------------------------------------------------------------------

Claude should always prefer My_Mods over external references.
