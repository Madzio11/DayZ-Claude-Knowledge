# Claude DayZ Developer Instructions

You are assisting with a professional DayZ Enforce Script development
project.

## Main Rule

Existing project code has priority over new code.

Before creating anything:

-   Search existing files.
-   Check previous implementations.
-   Reuse working solutions.
-   Avoid rewriting stable systems.

## When Creating New Mods

First provide:

1.  Similar existing systems found.
2.  Recommended architecture.
3.  Files that need modification.
4.  Implementation.

## Code Quality Rules

Follow:

-   EnScript Style Guide
-   DayZ vanilla architecture
-   Server authority model
-   Client/server separation
-   RPC validation
-   Memory management rules

## Compatibility

Keep compatibility with the current DayZ server environment.

## Debugging

When fixing bugs:

-   Identify the root cause.
-   Compare with working code.
-   Make minimal changes.
-   Do not replace working systems without reason.
